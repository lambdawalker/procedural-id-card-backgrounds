# Target State Driver License Specimen References & Visual Analysis

This document compiles the reference research and visual inspection of public driver-license specimens for the ten target states. All backgrounds generated in this project are 100% original procedural artwork inspired by these references. As required, all text, portraits, personal data, barcodes, official seals, and state outlines are strictly excluded.

---

## 1. Alaska (AK)
- **Authority / Issuer**: State of Alaska Department of Administration (DOA), Division of Motor Vehicles (DMV)
- **Specimen Edition**: Alaska REAL ID Driver License Specimen (Current Standard Edition)
- **Source Page URL**: `https://doa.alaska.gov/dop/ppdb/SOP/Ch16CDLPolicy/`
- **Image / Document Reference**: `https://doa.alaska.gov/dop/ppdb/SOP/Ch16CDLPolicy/SOA_CDL_Policy.pdf` (State of Alaska Credential Policy & Specimen Standard)
- **Public Domain / Repository Mirror**: `https://commons.wikimedia.org/wiki/Category:Driver%27s_licenses_of_the_United_States`
- **Observed Composition**: Dominant left-to-center mountain massif silhouette (Denali) rising from the lower third into the sky. Sub-arctic tundra and braided glacial river contours across the lower third. Undulating ribbons of Aurora Borealis waving across the upper sky.
- **Observed Color Palette**: Glacier Cyan: `#a8dadc`, Ice Blue: `#457b9d`, Deep Arctic Navy: `#1d3557`, Pale Aurora Emerald: `#52b788`, Frost Silver: `#f1faee`.
